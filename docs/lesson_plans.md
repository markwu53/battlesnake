# Lesson Plans

## Pedagogy

### Topics

Here are some of the concepts we will explore as a group:

- Python
    - Test-driven Development
    - Mocking
    - Test Case Fixtures
    - Typing
    - Exception-handling
    - Logging
    - Object-oriented Programming
    - Inheritance
    - Composition
    - Dependency Injection
- Visual Studio Code
- GitLab
    - git branches and commits
    - Best-practice deployment methodologies
    - Pull Requests

I hope this program exposes you to additional topic that you explore independently. For example, this project will
support independent experimentation with IaaC deployment methods, machine learning, and Monte Carlo simulations.

### Expectations

- **This is not a passive listening exercise.**
- If you are attending a session, I expect to be able to ask you to share your screen to demonstrate a concept.
- Lessons will be recorded. If you miss a lesson, I expect you to watch the recording and be familiar with the previous
  week's concepts by the beginning of the next session.
- Clarifying questions are a sign of active listening. If you have a question, posing it could help your fellow
  participants and improve the course content for the next cohort. That being said, **I do not want to punish engaged
  learners by playing catch up with unengaged learners.**
- Checkins: Each lesson will have "checkins" that will require you to provide some acknowledgement that you're keeping
  up with the group.
